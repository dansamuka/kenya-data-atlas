# Kenya Data Atlas v1.0.0 — Unresolved items register

This register records known evidence or operating constraints that remain intentionally unresolved at v1.0.0. None is hidden by imputation, inheritance or unsupported inference.

## 1. Narok fiscal-delivery score — withheld

**State:** known data limitation; non-blocking for v1.0.

The FY2024/25 fiscal-delivery layer requires a complete common-period input set. Narok does not receive an overall fiscal-delivery score because the required pending-bills source does not contain a submitted county value. The Atlas does not impute that missing evidence merely to make the ranking 47/47.

**Resolution path:** activate a source-backed comparable pending-bills value in a later data revision and regenerate the delivery layer under the same published methodology.

## 2. Mandera East / Lafey ward spatial hold — statistical rows retained, polygons withheld

**State:** known geography reconciliation limitation; non-blocking for v1.0.

Ten IEBC ward rows in Mandera East and Lafey remain in official statistical totals but are deliberately withheld from ward-polygon attribution because the statistical and spatial boundary sources cannot yet be reconciled with sufficient confidence. County and constituency totals remain intact; the Atlas does not force those rows onto uncertain polygons.

**Resolution path:** reconcile against an authoritative boundary/code source and publish the crosswalk before enabling those polygon joins.

## 3. Historical longitudinal composite — not released

**State:** methodological evidence limit; non-blocking for v1.0.

The current County Development Snapshot is a cross-sectional research result with published robustness diagnostics. A longitudinal composite remains withheld because historical county coverage is insufficient across the full indicator set and the reconstructable historical sub-index does not meet the stated stability standard. v1.0 therefore does not imply a validated long-run county performance index.

**Resolution path:** extend matched historical county observations across the required domains, rerun stability/back-testing and publish a separate methodology decision before promotion.

## 4. P14 programme freshness — ongoing operating obligation

**State:** maintained v1.1 Beta layer; not a v1.0 statistical release blocker.

The P14 Action & Opportunity Finder depends on external programme/application surfaces that can change independently of the Atlas. Live records therefore carry verification and next-review dates and are downgraded when freshness expires. County relevance is not personal eligibility.

**Resolution path:** continue the documented monthly freshness review and update programme states, terms and source claims only from primary programme sources.

## 5. External source links — availability can change after release

**State:** normal external dependency risk; non-blocking for v1.0.

The release audit checks internal links deterministically and inventories external links, but official publishers can move, block or retire URLs after the release. A later broken external URL does not retroactively invalidate the statistical value, provenance record or release checksum, but it may require an evidence-link maintenance update.

**Resolution path:** retain source identity and citation metadata, distinguish inaccessible/not-found/not-published states, and repair links only when an authoritative replacement is verified.

## Release rule

These limitations are disclosed because the release is considered complete only when uncertainty and missing evidence are visible. They must not be resolved by silent interpolation, geography inheritance, causal attribution or fabricated source terms.
