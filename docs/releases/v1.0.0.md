# Kenya Data Atlas v1.0.0

Kenya Data Atlas v1.0.0 is the first closed, reproducible public release of the Atlas statistical/data product.

The release covers the Kenya → County → Constituency → Ward geography hierarchy, canonical indicators and historical series, CountyIQ analytical products, county rankings and fiscal-delivery outputs, the County Evidence & Knowledge Hub, public developer distributions, and the separately governed P14 Action & Opportunity Finder Beta.

## Reproducibility

The v1.0 tag is created only after the exact release commit passes all of the following on `main`:

- `npm run build:data` with no committed generated-output drift;
- the complete `npm test` validation chain, including P14, P15, P16 and P17 release-state checks;
- the independent Python/Shapely geometry audit;
- the published distribution manifest and checksum inventory;
- an exact-commit GitHub Pages deployment.

The release manifest is `data/release/v1.0.0.json`. The stable developer distribution entry point remains `data/distribution/manifest.json`, with integrity hashes in `data/distribution/checksums.sha256`.

## Browser and accessibility

The exact release commit must also pass the P16 public-launch gate:

- Chromium, Firefox and WebKit critical-route smoke tests;
- automated axe checks for critical WCAG failures;
- 390px mobile keyboard, focus and horizontal-overflow checks;
- Lighthouse cold-load budgets for Home, Compare and CountyIQ;
- deterministic internal-link checks plus an advisory external-link inventory;
- robots/sitemap and crawlability checks.

The v1.0 publisher does not create the release tag until GitHub Pages has deployed the exact release commit and the public site passes a post-deployment smoke test.

## Data and product scope

At the v1.0 release candidate baseline the canonical public distribution contains:

- 1,788 geographies;
- 98 indicators;
- 3,370 series;
- 6,864 observations;
- 50 datasets;
- 47 CountyIQ county profiles/results;
- 247 county evidence records;
- a 9-programme P14 Beta opportunity registry subject to its own freshness policy.

Counts in this note are descriptive. The machine-readable release and distribution manifests are authoritative if a later maintenance release changes them.

## Governance

The release preserves the Atlas's publication boundaries:

- no parent-geography value is silently inherited downward;
- survey uncertainty and ranking restrictions remain explicit;
- the current County Development Snapshot is not presented as a historically validated longitudinal index;
- county administration records do not become personal causal governor scores;
- missing fiscal evidence is not imputed to complete a league table;
- P14 county relevance does not establish personal programme eligibility.

## Known limitations

Known unresolved evidence constraints are intentionally retained rather than approximated away. See `docs/releases/v1.0.0-unresolved.md` for the release register, including the withheld Narok fiscal-delivery score, the Mandera East/Lafey ward spatial hold, the longitudinal-composite limitation, P14 programme-freshness obligations and external-link volatility.
