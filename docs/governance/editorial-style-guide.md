# Editorial style guide

## Voice

Use clear, calm, neutral English for an intelligent non-specialist. State what the data shows without judging an institution, place or population.

Preferred:

> Nakuru’s value was 62% in FY2025/26 Q3, compared with a county median of 58%.

Avoid:

> Nakuru performed well and is efficiently managed.

The first statement is descriptive. The second introduces an unsupported judgment and causal interpretation.

## Required number context

Whenever space permits, show:

- indicator name;
- value and unit;
- reference period;
- geography;
- source;
- quality/method badge.

Detailed views additionally show source release, publication date, Atlas update date, methodology and limitations.

## Dates

Use unambiguous dates such as `26 August 2026`. Fiscal periods use the source form, for example `FY2025/26 Q3`. Do not describe a publication date as the observation period.

## Numbers and units

- Retain source precision unless an approved display rule rounds it.
- Never add decimal precision not supported by the source.
- Use `KES` in data labels and metadata; prose may use “Kenyan shillings.”
- Define percentage-point change as `pp`; do not confuse it with percent change.
- Use non-breaking meaning where possible: `km²`, `%`, `KES 2.4 billion`.
- Provide exact downloadable values even when interface values are abbreviated.

## Geography

Use the official display name and level on first reference: `Nakuru County`, `Ol Kalou Constituency`, `Kaimbaga Ward`. Never use “sub-county” and “constituency” interchangeably unless describing an approved crosswalk.

## Missing data

Use a plain reason, not zero:

- “Data not currently available at ward level.”
- “Not published for this reference period.”
- “Suppressed by the source.”
- “Awaiting quality review.”

Do not say “No data” when a more precise status is known.

## Estimates and derivations

Use the method in the label:

- “Official-derived value”;
- “Spatially derived estimate”;
- “Modelled estimate.”

Do not use “official” by itself for a derived or modelled value merely because official inputs were used.

## Change and comparison

Use “increased,” “decreased” or “changed” only across methodologically comparable observations. State the period. Avoid “improved” or “worsened” unless the indicator’s direction and interpretive limitations are explicitly defined.

## Sources and citations

Charts and tables cite the immediate agency and release. Source links lead to the Atlas source/release record and, where permitted, the original publication. Do not rely on a global footer for attribution.

Suggested citation:

> Source: Kenya National Bureau of Statistics · [release title] · Reference period: [period] · Atlas series: [ID].

## Demo content

Demonstration figures must be labelled `Demo` in the component and accompanied by a page-level demonstration notice. Never use agency branding or wording that could make an illustrative value appear agency-approved.
