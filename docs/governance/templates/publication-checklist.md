## Source and rights

- [ ] Source assessment is approved and current.
- [ ] Original file/response is archived with URL, retrieval time and hash.
- [ ] Public reuse and redistribution are permitted for the proposed outputs.
- [ ] Required attribution and licence text are attached.

## Statistical integrity

- [ ] Every indicator definition, unit, frequency and aggregation rule is approved.
- [ ] Every observation has geography, reference period, method and provenance class.
- [ ] Derivations are reproducible and input observations are retained.
- [ ] Geographic transformations, weights and boundary versions are documented.
- [ ] Provisional, suppressed, estimated and missing statuses are preserved.
- [ ] Comparison and ranking eligibility has been assessed.
- [ ] Methodological breaks and limitations are documented.

## Validation

- [ ] Schema, uniqueness, code, unit and hard-bound checks pass.
- [ ] Expected-versus-observed coverage is reviewed.
- [ ] Totals/components and cross-source reconciliations pass where required.
- [ ] Anomalies and revisions have reviewer dispositions.
- [ ] Website, API and download samples agree exactly.

## Privacy, security and accessibility

- [ ] No prohibited personal or household-level data is present.
- [ ] Suppression and small-cell requirements pass.
- [ ] Files contain no secrets, private paths or internal-only metadata.
- [ ] Public labels, sources, missing states and quality badges are accessible.
