# HDX boundary source files

These source sidecars were downloaded on 26 August 2026 from publicly accessible Humanitarian Data Exchange resources.

## Selected sources

- `kenya-elections-2018/counties.*` and `constituencies.*`: [Kenya Admin Boundaries — Election Polling stations](https://data.humdata.org/dataset/kenya-elections), modified 16 August 2018. The HDX record identifies IEBC as its source. The archives contain 48 county and 295 constituency source records; the ingest process promotes exactly the 47 and 290 records that reconcile to the canonical registry and reports unused extras.
- `administrative-wards-1450-2019/kenya_wards.*`: [Administrative Wards in Kenya 1450](https://data.humdata.org/dataset/administrative-wards-in-kenya-1450), modified 12 April 2019, published by the American Red Cross. It contains exactly 1,450 WGS84 ward records.

HDX states that, except where otherwise noted, its content is licensed under Creative Commons Attribution 4.0. Preserve the source page, original publisher attribution and the file hashes recorded by the ingest report when redistributing derived geometry.

These are external operational boundary sources. They are not labelled as official-direct or as an IEBC endorsement.
